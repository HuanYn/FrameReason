# 复现范围与结果边界

本仓库提供 **FrameReason 的最小训练/评测流程、历史结果证据和静态视频回答 Demo**。它不是完整实验服务器镜像，不含模型权重、优化器状态或完整 CLEVRER 数据，也不保证换一台机器重新训练后得到完全相同的浮点结果与最终分数。

## 1. 三种“复现”要分开

| 层级 | 仓库支持的内容 | 不应据此声称 |
| --- | --- | --- |
| 历史结果复核 | 对齐 800 个精确题目键，重计 2400 条保存回答的历史正确性标签，检查配对计数、文件哈希与 3000 组奖励 | 重新运行过模型；已经独立重评分全部官方标签 |
| 最小流程复现 | 用户准备官方数据与基座后，执行八帧转换、LoRA SFT、规则奖励 GRPO 和评测 | 已发布历史 adapter；必然重现 76.125% |
| 字节级/数值级实验复现 | 提供模型 revision、历史配置、原始文件摘要、确切测试题目身份作为定位依据 | 提供了历史全部权重、输入帧字节、运行环境和训练中间状态 |

历史运行配置见 [`results/historical-config.json`](../results/historical-config.json)。发布代码是面向学习与复现的整理版本；源码存在某个功能，不等于历史主线执行过该功能。

## 2. 无 GPU 的结果复核

在仓库根目录运行：

```bash
python results/verify_results.py
```

仅需 Python 标准库。该命令检查：

- 800 个唯一 `(video_id, question_id)` 与三模型回答完全对齐；共有 754 个视频、四种题型各 200 题。
- 保存的 `<answer>` 与展示答案一致，历史正确性账本得到 Base 343、SFT700 609、GRPO3000 606。
- GRPO 相对 SFT 纠正 59、丢失 62、均对 547、均错 132。
- 3000 个唯一训练步中，2659 组奖励相同；这些组记录的优势全为零；2659 步记录的 `grad_norm` 为零。
- 10 道附带官方参考答案的 Demo 题可以实际重新评分，而非仅相信其历史标签。

默认检查的 `full_ground_truth_rescore_completed` 明确为 `false`：公开包中没有完整的 800 道官方 GT，仅有 10 道 Demo 参考记录。`answer_correct` 是历史评分证据，不是根据模型输出临时合成的“真值”。哈希用于发现文件意外变更，并不构成第三方签名认证。

如果已经用仓库的数据转换流程准备好带官方 `solution` 的测试 JSONL，可以独立重评分全部 2400 条保存答案：

```bash
python results/verify_results.py --reference-jsonl data/grpo_test.jsonl
```

该文件可包含完整父测试集，也可只包含最终 800 题；必须覆盖全部公开题目键。检查会拒绝缺题、重复键、题型变化和任何与历史正确性不一致的答案。这个附加步骤是 **答案层面的 CPU 重评分**，不重新推理，也不重新执行完整程序匹配评分。本次公开整理没有完整官方参考文件，因此没有把这条可选命令写成已实际完成的全量评分结果。

## 3. 复用精确的固定 800 题

历史父测试集为 4000 题、四类各 1000，来源是 CLEVRER 官方 validation；这不是官方隐藏 test 或官方 leaderboard 协议。主线只完成固定 800 题，每类 200。

[`subset800.jsonl`](../results/subset800.jsonl) 发布全部精确身份与原始预测顺序。已转换出带官方标签的测试 JSONL 后执行：

```bash
python results/select_subset.py \
  --input data/grpo_test.jsonl \
  --output data/compact800.jsonl
```

输出文件必须尚不存在。脚本按公开的精确键提取，不按模型正确性选题；保留调用者自己的图像路径。因此它复现题目身份和顺序，而不是历史机器上含绝对媒体路径的 JSONL 字节。若转换得到的父集缺少某道历史题，脚本会直接报错，不静默换题。

历史抽样规格见 [`sampling-spec.json`](../results/sampling-spec.json)：以 seed 42 和题型、视频 ID、问题 ID 构造 SHA-256 排序键，每类取前 200；答案、程序和模型输出不进入排序键。公开精确题目清单是复用最终子集的直接依据。

## 4. 已完成结果及限制

| 模型 | 答案正确 / 总题数 | 准确率 |
| --- | ---: | ---: |
| Qwen3-VL-4B-Instruct Base | 343 / 800 | 42.875% |
| LoRA SFT700 | 609 / 800 | 76.125% |
| 固定 GRPO3000 | 606 / 800 | 75.750% |

观察：SFT 相对 Base 增加 266 题、33.250 个百分点；相对准确率变化为 +77.551%。GRPO 相对 SFT 少 3 题、0.375 个百分点；相对准确率变化为 −0.493%。GRPO 改变了部分题目的正确性，但没有带来净提升。

解释：2659 / 3000 = 88.633% 的训练组奖励相同，对组内相对优势没有区分信号。在本次 `beta=0` 的配置下，没有额外 KL 项提供该处的策略梯度。该现象是学习信号稀疏的证据，**不能证明它是未涨分的唯一原因，也不能证明优化器参数在所有零梯度步绝对不动**。

结论边界：单 seed、自定义题型均衡子集、部分问题来自同一视频、开发集选模机会不对称、最终测试集现已被查看；没有多 seed 显著性、官方 CLEVRER 榜单、SOTA 或物理因果模拟结论。达到 3000 步、loss 接近零不等于收敛或泛化改善。

训练使用八张均匀抽取的图像，而 Demo 展示对应原始视频。公开程序 trace 是模型生成的可读结构，不是已经执行的物理模拟器，也不是隐藏思维过程的真实性证明。现有实验未证明教师学生优化有效；实际 Video-OPD 学生训练没有进入已完成主线，不写成成果。

项目已收束。本页提出的可选复核入口不表示正在安排新训练或追加实验。
